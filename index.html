// اختبار أخلاقي معتمد — Ethical Mode

الوضع الافتراضي فحص Black-box مجهول: لا تحتاج إلى Cookie أو Token. يزحف الماسح ضمن النطاق نفسه، يقرأ روابط HTML وJavaScript وrobots/sitemap، ويسجل الحقول دون إرسال النماذج أو تخمين بيانات الدخول.

فحص الصفحات المحمية (اختياري)

تُرسل بيانات الدخول مؤقتًا أثناء الفحص ولا تُحفظ في السجل أو التقرير. استخدم جلسة اختبار محدودة الصلاحيات وعلى هدف تملك إذنًا لفحصه. لا تغيّر User-Agent لتجاوز الحظر. Nuclei وffuf وHTTP probes تدعم هذه الخيارات؛ تُعلّم الأدوات الأخرى كمتخطاة مع السبب.

لمنع إرسال أسرار الفحص عبر مضيف بعيد، يُقبل البروكسي المحلي فقط (Burp/ZAP مثلًا). عند تفعيله لا تعمل إلا الأدوات المعلَن دعمها له.

محركات اختيارية — تحتاج إعداد API محليًا

SQLmap API: يعمل تلقائياً في النمط العميق بعد تأكيد الفحوص النشطة؛ فحوص Boolean/Error/Union محدودة، تتطلب رابطاً بمعاملات، ولا تستخرج بيانات. يتطلب API محلياً وهدفاً ضمن النطاق المصرح.

تعمل هذه التكاملات فقط في نمط «عميق» وعند ضبط عنوان API محلي؛ ستظهر حالة التخطي وسببها في التقرير.

🤖 الوكيل الأمني (AI Agent)

يعمل فقط بمفتاح AI API

الوكيل يفحص الهدف بدقة (استطلاع + اكتشاف ثغرات) ثم ينفّذ الاستغلال وجلب البيانات كأدلة إثبات. الفحص العادي بدون استغلال متاح للجميع؛ لتفعيل الاستغلال أضف مفتاح AI API من الإعدادات. اكتب رابط الهدف في خانة الهدف أعلاه لنتائج أدق.
